## Code changes

Made the code that calcuated the date-time in the footer of the printed page update every 30 seconds, and as a composable instead of scattering the code across 3 files.

Now to make a page printable like the character sheet pages are, you only need to add the following code to the setup of the Vue page component:

```javascript
<script setup>
  
usePrintSetup();

</script>
```
