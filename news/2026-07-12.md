## Code changes

Made the code that calculated the date-time in the footer of the printed character sheet page update every minute.
Implemented as a composable instead of scattering the code across 3 files.

Now in order to make other pages printable like the character sheet pages are, you only need to add the following 
code to the setup of the page's Vue.js component:

```javascript
<script setup>
  
usePrintSetup();

</script>
```
